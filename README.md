# my-first-bevy-game

My first 3d game powered by bevy engine.

also a experiment of rendering, may be slow in some platforms.

# Development Tool

- Game Engine: [Bevy](https://github.com/bevyengine/bevy)
- Music Composing Tool: [Audacity](https://github.com/audacity/audacity)
- Sound Effect Generator: [sfxr](https://github.com/grimfang4/sfxr)

# Note for Windows

Better using **x86_64-pc-windows-gnu** the rust toolchain to compile for Windows.
To check for a custom build target: `rustup target list` and build your target.
